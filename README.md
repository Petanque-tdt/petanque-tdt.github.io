# Tournoi de pétanque — Soirée du personnel 2026

Application web (GitHub Pages + Firebase Firestore) pour gérer le tournoi en doublettes :
tirage des équipes inter-sociétés, système suisse, classement Elo, saisie des scores sur smartphone (FR/EN).

- `config.js` : configuration Firebase, code organisateur, charte
- `logic.js` : tirage, appariements, Elo, terrains (testable sous Node)
- `app.js` : interface
